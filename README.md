# highcans.com.my

The public website of High Cans Corporation Sdn Bhd, served by GitHub Pages
at <https://www.highcans.com.my>.

It is ten plain HTML pages with their styles inline: no build step, no
images, no scripts. To change the site, edit a page and push to `main`;
GitHub Pages publishes it within a minute or two.

- `CNAME` tells GitHub Pages which domain to serve. Leave it alone.
- `.nojekyll` makes GitHub publish the files exactly as they are.
- `.gitattributes` stops git from rewriting line endings.

The pages were copied from the previous host (Rapid Cloud, Windows/IIS) on
6 October 2026 and are unchanged from what that server was sending.
